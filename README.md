# Task Manager

A simple command-line Task Manager built using Python.

## Features

The application supports:

- Add a task
- List tasks
- Mark a task as completed
- Delete a task
- Exit the application

## Project Structure

task-manager/
│
├── README.md
├── requirements.txt
│
└── src/
    ├── __init__.py
    ├── main.py
    ├── task.py
    └── task_manager.py

## Requirements

- Python 3.x

## How to Run

Open the terminal inside the task-manager directory.

Run:

python src/main.py

## How It Works

Tasks are stored in memory while the application is running.

Therefore, tasks will be lost when the application is closed.
